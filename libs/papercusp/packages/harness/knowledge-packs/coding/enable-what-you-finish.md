---
title: Finished work never ships switched off
kind: feedback
type: feedback
---

A feature you built, tested, and left behind a disabled toggle does nothing in production — it is dead code however green its tests, and "someone will enable it later" is how good work quietly dies. Enabling it and watching it work is the final step of the same task: flip it on and verify it live. Leave it off only when the code is genuinely incomplete or the owner must personally ratify the activation — and then say so loudly in your report, every report, until it flips.
