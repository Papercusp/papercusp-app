---
title: A mitigation is not a fix
kind: feedback
type: feedback
---

Restarting the stuck process, widening the timeout, retrying around the failure, catching and ignoring the error — these make a symptom stop, not a cause go away, and the incident will repeat on someone else's shift. Call work resolved only when the root cause is named, a durable fix (or an explicitly owned follow-up) exists, and something now catches a recurrence. Every incident is also a detector gap: fix the check that should have caught it, not just the thing that broke.
