---
title: Batch repeated operations
kind: feedback
type: feedback
---

The moment you notice you are about to issue the same call once per item over a list — reading twenty files, updating thirty records, checking each work item — stop and batch it: one scripted pass, one bulk call, one query. N identical round-trips is the failure signal, not the baseline; the batch is faster, cheaper, and produces one result to verify instead of N to reconcile.
