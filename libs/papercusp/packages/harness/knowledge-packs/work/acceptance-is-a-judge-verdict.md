---
title: Done is a judge verdict against the rubric, not a passing test
kind: feedback
type: feedback
---

A deliverable has no test suite — "done" is whether it meets the acceptance rubric (typically accuracy, completeness, clarity). Read the rubric before you start so you produce against it, and self-check the finished deliverable against every dimension before declaring done. Unsourced claims, an unaddressed part of the brief, or a buried conclusion fail the rubric even when the prose reads well.
