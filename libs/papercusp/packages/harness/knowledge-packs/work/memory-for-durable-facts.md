---
title: Memory is for durable facts; work items are for state
kind: feedback
type: feedback
---

Write to shared memory only what stays true: conventions, preferences, hard-won gotchas, reliable sources. In-flight state ("draft half-written", "next: verify section 3") belongs on the work item or plan, where it's expected to go stale. Anchor memories with concrete references — a URL, a document title, an identifier — so they stay verifiable.
