Consolidation rule

Catalog in the main tab. Attention in the middle pane.

The middle pane becomes smaller and calmer because identity, configuration, scheduling, history, and spend live on the full Automations surface.

Before · fragmentedAgents + System + background tasks
  • Overlapping inventories
  • Schedule and spend live elsewhere
  • Enabled is mistaken for running
→
After · consolidatedAutomations + workspace pulse
  • One durable automation identity
  • All controls and costs in one place
  • Middle pane carries only live attention
ScheduleEnabled, paused, and next-run state stay independent.
ExecutionRunning now is actual work, never inferred from a schedule.
SpendOnly attribute cost when a run carries a verified source link.
