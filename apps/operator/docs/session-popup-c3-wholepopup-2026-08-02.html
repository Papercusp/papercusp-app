C3 everywhere, in three characters

Same treatment you picked, now carried across the top bar, both rails, the transcript, the composer, the control band and the fleet strip. All three looks below are one markup with one set of tokens swapped — which is the point: if a look needed different structure it would be a different design, not a different skin, and you could not change your mind later for free.

The constraint that shapes all three

Fills are a dead end at every scale here

The same measurement that sank C v1 also rules out the obvious way to separate the columns.

The natural way to make three columns read as three zones is to tone them differently — rails darker, conversation lifted. Measured on this ground that gets you 1.19:1 between a #081220 rail and a #142339 conversation. Invisible, exactly like the 1.11:1 card fill was.

So every look below separates zones with a rule, not a tone — and #5182a0 against a deep rail measures 4.52:1. Same lesson as the rails: on this palette, structure comes from stroke, cap and type. Tone is a garnish that cannot carry meaning.

Choosing

What actually separates them

All three fix the same things: sections are bounded by a stroke that clears the floor, headings sit in a cap instead of being the quietest text in their own section, settled sections collapse to one dim line, and the control band, composer and fleet strip stop being visually unrelated to the rails.

Instrument is the most literal reading of C3 and the loudest. Count the accent blocks: eleven, all equally bright, which re-creates the flatness at higher volume — the wall you need and the mission you don't are equally vivid.

Signal keeps every structural gain and spends accent only where something is actually true: four instances instead of eleven. A neutral cap still measures 10.92:1 for its text, so nothing is harder to read — the section names simply stop competing with the states. This is the one I'd ship.

Framed is the most opinionated. Naming the zones is a real usability gain when both rails are open, and it is the only look where the three-column architecture is stated rather than implied. It costs a header row per rail and reads more like an IDE than a chat popup — worth it if you keep both rails open, over-built if you mostly run with them closed.

These compose. Signal's cap policy and Framed's zone titles are independent — you can have named zones with quiet caps. If you want that, say so and it's the same build with both token sets applied, since all three are one markup.

Ratios are sRGB relative luminance per WCAG 2.1 against the surface each element sits on. Mockups use the live token values from app/_semantic.css and the real rail content; the three looks share one markup and differ only in the tokens set on .pop. Nothing here is implemented yet — the quiet-empty rule is a render branch in the rail components, everything else is CSS.
