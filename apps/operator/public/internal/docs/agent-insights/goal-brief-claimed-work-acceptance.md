# Goal brief to claimed work: acceptance procedure

This procedure supports `goal-brief-to-claimed-plan-work-2026-09-23` and its acceptance rubric. Read the current plan Design, Decisions D-001 through D-008, current rubric revision/criteriaHash and each complete method before grading. It reuses the existing acceptance-rubric vetting and GOAL grading rails; it creates no new evidence ledger or instrument.

## Pin the evidence

Record canonical staging tree SHA and the serving staging operator `:3170` build SHA. Current-build/staging is the implementation and organic-trial acceptance plane specified by Design. Green main/`:3070` is reserved for final shipment. Record the actual runtime and build beside each live finding; a refusal from an older runtime does not prove the current implementation is absent.

Run named tests through the project's testing router. Before interpreting a verdict require matched files equal requested files, no route errors and no silently skipped requested tests. Name the assertion, fixture or mutation that detects each failure, not only the file and pass count. Reuse still-current bound proof; rerun when source fingerprints or the promised detection change.

## Separate outcomes and causal attribution

R-1 judges scoped need selection; R-9 judges action priority and review timing. R-6 judges the standard rubric's removal of production quotas; R-8 judges planning scope and ownership. A single quota defect can contradict several promises but is one causal finding: cite that same finding with each criterion's distinct observation instead of counting it as several independent defects.

R-2 grades pickup/repair within the eligible opportunity bound, R-3 delivery continuity, R-7 matched behavioral comparison and the full organic chain, and R-10 origin-preserving feedback. They may share P-007 records but need distinct evidence slices. Missing P-007 trials are one shared unmet prerequisite, not four measured behavioral regressions. Cross-references do not discharge any mandatory clause.

Generic stored drift markers are supplemented by each method's concrete FALSIFIED observation. Structured bindings must test those observations; a resolved path alone is insufficient. Missing/unreadable/omitted evidence is unknown. Absence claims require an enumerated, complete population of possible violators, with checked, not checked, not applicable and residue recorded explicitly.

## Organic trials and safety

P-007 requires two independent fresh current-build GOAL trials matched to baseline scenarios: necessary goal-local planning without a Blender proposal, and suitable Blender-plan adoption without duplication. Each record links exact non-omitted brief/source generation to independent leader, positive scheduler filter, delegated lease, member claim, organic terminal result, verification, feedback and report. Record model/effort, workload, provenance, actual cost and unknowns. Include sufficient-plans, no-demand, blocked-budget, missing-delivery and cross-goal controls.

Do not substitute formatter/unit/integration fixtures, proposal counts or launch receipts for organic behavioral evidence. D-004 forbids new telemetry-only subject launches, fabricated spend, wider budget/admission authority and red-gate bypass. P-007 runs only inside already authorized real work and normal measured budget/admission. The separate behavior-feedback plan P-004 pause remains in effect under D-008.

## Review and closure

Complete evidence binding before final spec adequacy and independent plan grading. Preserve historical scorecards. A method-only amendment must preview unchanged BAR hashes and no invalidated proof. Adding a check, changing a falsifier or declaring evidenceRuntime uses the canonical started-BAR preview and outside-lineage review; retain the exact approval and invalidated-proof list, then refresh only the affected evidence.

Use the existing rubric-vetting consult and current-revision meta attestation. Grade weaknesses honestly; meta vetting is about rubric fitness and is not acceptance of the implementation. Independent plan grading and author acceptance remain separate. Keep P-009 open until its independent adequacy audit settles. Final shipped status requires the normal green promotion/deployment evidence and the established live-gate owner's control of that lane.
