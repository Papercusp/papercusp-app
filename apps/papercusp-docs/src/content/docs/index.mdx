**Papercusp** brings your apps, workspaces and AI agents together. Use the
[web portal](https://app.papercusp.com/) to manage work in your browser, or a
Papercusp desktop installation to work with a connected computer.

This is the **public user manual**. You can read and search it without an
account. The portal's **Project docs** destination contains documentation for
your selected project; internal engineering documentation is a separate,
authenticated surface. Neither is published here.

## A few useful words

A **workspace** is the environment your work runs in. A **harness** is a
managed project within that environment. A **plan** records a goal, work items
and acceptance conditions. An **agent session** is a conversation that performs
work with the permissions it has been given. A **template** is a maintained
starting point for an app; a **plugin** adds capabilities.

Papercusp is evolving. Available providers, templates, cloud options and
integrations depend on your installation and permissions. These guides explain
the current workflow without promising that every option is enabled for every
account.

## Source and feedback

The public source repository is
[Papercusp/papercusp-app](https://github.com/Papercusp/papercusp-app).
For a problem with your installation, use **Support** in the portal and include
what you tried and the exact error. Never include passwords, access tokens or
private project content in a public report.
